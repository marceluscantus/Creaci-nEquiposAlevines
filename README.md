# Cuatro cuartos · Balonmano

Aplicación estática para GitHub Pages. Contiene los 20 nombres; dorsales y puntuaciones inicialmente vacíos. Cada entrenador puede añadir/quitar jugadores y editar sus datos, guardados automáticamente en su navegador. No hay sincronización ni envío de plantillas a un servidor.

## Publicar gratis
1. Crea un repositorio público en GitHub, por ejemplo `cuatro-cuartos`.
2. Descomprime el ZIP. Sube los archivos de esta carpeta a la raíz del repositorio (no el ZIP), incluido index.html.
3. Settings → Pages → Source: Deploy from a branch → main → /(root) → Save.
4. Abre el enlace que muestre GitHub Pages cuando termine la publicación.

Guía oficial: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Instalar
iPhone: Safari → Compartir → Añadir a pantalla de inicio.
Android: menú del navegador → Instalar aplicación / Añadir a pantalla de inicio.
Abre la app instalada con internet y espera el mensaje «Lista para funcionar sin conexión». Después podrá arrancar sin conexión mientras el navegador conserve la caché.

## Datos
Los nombres incluidos serán públicos. Las puntuaciones y dorsales que cada entrenador introduzca permanecen en su dispositivo y navegador. Si borras los datos del navegador, puedes perderlos. Exporta con Guardar plantilla para copia de seguridad e importa con Abrir plantilla; funciona también con las plantillas de la versión HTML anterior. La instalación en pantalla de inicio puede tener almacenamiento separado del navegador: importa la copia allí si es necesario.

## Actualizar
Sube los archivos actualizados al mismo repositorio. Incrementa v1 en sw.js cuando cambies los archivos en caché. No cambies la dirección de la app para conservar la clave de almacenamiento.

## Alcance
Todos los convocados participan. Entre 10–14: 2–3 inicios; entre 15–18: 1–2 inicios. Esta última participación mínima es un criterio de la herramienta. Es una propuesta heurística, no un óptimo matemático. Consulta las reglas y limitaciones dentro de la aplicación.
